# Survivor Box Games

Laboratorio de desenvolvimento de jogos simples para browser.

## Objetivo

Este repositorio vai reunir experimentos jogaveis em HTML, CSS e JavaScript, com foco em jogos leves que possam ser publicados online.

## Estrutura

- `index.html`: hub inicial com links para os jogos.
- `src/`: estilos e scripts compartilhados.
- `games/`: pasta para cada jogo independente.

## Publicacao

O projeto foi pensado para funcionar como site estatico e pode ser publicado pelo GitHub Pages.
